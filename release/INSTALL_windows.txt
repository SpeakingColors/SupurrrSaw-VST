SupurrSaw by Studio 87: install on Windows
==========================================

What is in this zip
  SupurrSaw.vst3   the plugin (a folder, keep it as it is)
  SupurrSaw.exe    the standalone app
  SupurrSaw_Manual.pdf   short manual
  LICENSE          AGPL-3.0-or-later

1. Unzip first (right click the zip, Extract All). Do not run things from inside the zip.

2. Install the plugin
   Copy the whole SupurrSaw.vst3 folder into  C:\Program Files\Common Files\VST3\
   (Windows asks for administrator permission). Restart your DAW or rescan plugins.

3. Or run the standalone app
   Double click SupurrSaw.exe.

Windows may show a blue "Windows protected your PC" window the first time, because the app is not signed yet.
Click "More info", then "Run anyway". Windows 10 or 11 is needed (the window uses the built in WebView2).

Your presets, saved waves, exports and the log are kept in your user folder under Studio 87\SupurrSaw.
The Files button inside the plugin opens them.

Free and open source. Source code and help: https://github.com/SpeakingColors/SupurrrSaw-VST

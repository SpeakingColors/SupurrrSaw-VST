# Mockups

Interactive HTML mockups of SupurrSaw. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [SupurrSawSeq](mockups/SupurrSawSeq.dc.html)
- [SupurrSawPresets](mockups/SupurrSawPresets.dc.html)
